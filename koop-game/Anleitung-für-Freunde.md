# KoopGame — Anleitung & Steuerung

Willkommen! Kurz das Wichtigste, damit ihr direkt loslegen könnt.

## Worum geht's?

Ein Koop-Multiplayer-Survival-Aufbauspiel im Zombie-Setting (Stil von
*Infection Free Zone*). Jeder Spieler baut auf einer gemeinsamen Stadtkarte
seine **eigene** Basis auf, schickt Trupps zum Plündern in verlassene
Gebäude, verteidigt sich gegen täglich stärker werdende Zombie-Horden und
kann mit den Mitspielern handeln oder sich gegenseitig zu Hilfe eilen.
Tagsüber sammeln und ausbauen, nachts verteidigen. Kein festes Spielziel/
Sieg — reines Sandbox-Überleben, das über die Zeit schwieriger wird.

## Wie startet man?

- **Hauptmenü:** Solo, Host oder Beitreten (Host-IP eingeben).
- Wer hostet, ist gleichzeitig Server UND ganz normaler Mitspieler — kein
  separater Server nötig.
- In der Lobby: Host drückt "Spiel starten". Wer später dazustößt, landet
  automatisch direkt in der laufenden Welt.
- Nach dem Laden: Jeder wählt selbst seine **Start-Basis** — anklicken
  irgendeines noch unbesetzten Gebäudes in einer Stadt-Zone. Kostenlos,
  keine Suche nötig.

## Steuerung

| Taste / Maus | Wirkung |
|---|---|
| **W A S D** oder Pfeiltasten | Kamera bewegen (schwenken) |
| **Linksklick** | Eigenen Trupp/Fahrzeug auswählen |
| **Linksklick (mit Auswahl) auf Boden** | Bewegungsbefehl |
| **Shift + Linksklick** | Auswahl erweitern / Ziel an bestehende Route anhängen (z. B. mehrere Gebäude nacheinander plündern) |
| **Rechtsklick + Ziehen** | Kamera drehen/neigen |
| **Rechtsklick (ohne Ziehen)** | Ausgewählte Einheiten stoppen |
| **Mausrad** | Zoom |
| **1–9** | Kontrollgruppe auswählen |
| **Strg + 1–9** | Aktuelle Auswahl als Kontrollgruppe speichern |
| **F** | Aus Fahrzeug aussteigen (Fahrer + alle Mitfahrer) |
| **M** | Vollbild-Kartenansicht öffnen/schließen |
| **Esc** | Pause-Menü (Speichern, Einstellungen, Spiel verlassen) |

**Gamepad (optional):** rechter Stick = Cursor, linker Stick = Kamera,
A = Linksklick, B = Stopp, LB/RB = Zoom, Start = Pause-Menü.

Die linke Spalte am Bildschirmrand (Wetter/Forschung/Herstellen/Bauen/
Einheiten/Trupp/Karte/Ereignisse/Handel/Überleben/Ausrüstung/Bücher) öffnet
per Klick jeweils ein Info-/Aktions-Fenster daneben. Oben mittig: Kalender,
Uhrzeit, Zeitraffer (1x/2x/3x, nur der Host sieht die Buttons) und Pause.
Oben rechts: Baurohstoffe + Zombie-Zähler. Unten rechts: Minimap.

## Grundablauf

1. **Start-Basis wählen** (siehe oben) — ihr bekommt automatisch fünf
   Feldtrupps und ein paar Start-Ressourcen.
2. **Plündern:** Feldtrupp auf ein Gebäude schicken — läuft hin, kämpft
   sich ggf. durch, durchsucht es, bringt Loot zurück. Danach könnt ihr das
   Gebäude für 15 Stein **claimen** (eigener Bauzonen-Anker).
3. **Bauen:** Drei Wege —
   - **Direkt platzierbar:** Wachposten, Mauer, Tor, Feld, Außenposten,
     Wachturm (Bauen-Tab, Ghost-Vorschau vor dem Platzieren).
   - **Ausbauen** eines eigenen, geplünderten+geclaimten Gebäudes:
     Krankenstation, Werkstatt, Lager, Schlafraum — läuft über
     "Baustellen": Ziel festlegen, Bautrupps zuweisen, Baufortschritt läuft
     über Zeit (schneller mit mehr Trupps).
   - **Herstellen-Tab** (braucht eigene Werkstatt): Waffen/Rüstung craften.
4. **Trupp-Arten:** Jeder Trupp ist entweder **Feldtrupp** (plündern,
   claimen, kämpfen) oder **Bautrupp** (abbauen, Baustellen bearbeiten) —
   umschaltbar per Button in der Einheiten-Liste. Neue Rekruten starten als
   **Zivilist** (unzugewiesen, bewegt sich nicht, grau) — müsst ihr erst
   zuweisen (manuell oder per Auto-Zuweisungs-Dropdown).
   **Farben:** eure eigenen Trupps sind Weiß (Feld) / Orange (Bau),
   Mitspieler bekommen jeweils ein eigenes Paar (z. B. Blau/Gelb) — so
   seht ihr auf einen Blick, wessen Trupp das ist und was er gerade macht.
5. **Bedürfnisse:** Hunger, Müdigkeit, Moral sinken über Zeit. Hunger
   erholt sich an der Home-Base (braucht Nahrung im Lager), Müdigkeit/Moral
   nur an einem eigenen Schlafraum. Baut den früh, sonst laufen eure Trupps
   dauerhaft im Debuff-Bereich.
6. **Nachts wird's gefährlich:** Ein Spieltag = 5 Echtzeit-Minuten. Jede
   Nacht kommt eine Zombie-Horde, jede 5. Nacht ein Blutmond (deutlich
   größer). Vorwarnung kommt jeweils vorher.
7. **Rekrutierung:** Neue Trupps über ein festes Rettungs-Gebäude pro
   Zone, Zufallschance beim Plündern, oder "Schutzsuchende", die alle paar
   Minuten irgendwo auftauchen.
8. **Fahrzeuge:** Auto/Motorrad/LKW in den Stadt-Zonen — einsteigen per
   Klick mit ausgewählten Trupps, schneller als zu Fuß, braucht Treibstoff
   (tankt automatisch an der Home-Base auf).
9. **Miteinander spielen:** Jeder hat seine EIGENE Basis/Ressourcen (kein
   gemeinsamer Topf), aber: gemeinsame Zombie-Gefahr, Handel (Schenken/
   Tauschen), gegenseitige Hilfe bei Angriffen (roter Ring auf der Karte),
   gemeinsam aufgedecktes Gebiet (Fog of War).
10. **Falls eure Home-Base fällt** (500 HP, selten): entweder ein
    Mitspieler schickt euch einen Rettungstrupp, oder ihr startet neu.

## Sonstiges

- **Speichern:** Pause-Menü (Esc) → Speichern (nur der Host).
- **Laden:** über den Hauptmenü-Button.
- Habt ihr Bugs/komische Sachen gesehen? Kurz notieren (am besten mit
  Screenshot) und melden — siehe die separate Test-Liste.
